# 右侧面板改版：子图统计、选择与渲染设置（参考 hnxwidget）

> 状态：第 1–3 期已实现（分支 `feat/inspector-panel`），第 4 期（移植到 Hypergraph-DB 与 Hyper-RAG）未做。实现中的偏差与附带修复见文末「实现记录」。

左侧栏保持不变（数据源、全库统计、全库实体列表，用来切换中心实体）。改的是右侧面板：从「只显示悬停详情」改为当前子图的统计、实体 / 超边表（选择、显示 / 隐藏、颜色）和渲染设置。

## 1. 现状

| 区域 | 现在 | 问题 |
| --- | --- | --- |
| 左侧 `Sidebar.jsx` | 数据源、全库实体数 / 超边数、全库实体列表 | 不改 |
| 顶栏 | 标题、超图 / 图模式切换、实体数 / 超边数、语言 | 模式切换保留在顶栏；计数在有隐藏时改为「显示数 / 总数」 |
| 画布 `GraphContainer` | 只能点**一条**超边高亮，点实体无反应 | 不能多选、不能隐藏；枢纽实体（NVDA 子图中「超大规模云」在 32/32 条超边里）把所有轮廓拉到中心，没有办法拿掉 |
| 右侧 `DetailsPanel`（w-72） | 最后悬停 / 选中的超边和实体属性 | 只有详情，没有子图层面的信息和控制 |
| 渲染参数 | 写死在 `hypergraph-viz/spec.ts`：`nodeSpacing` 50、标签防重叠开、图模式力导参数、主题色 | 无法在界面上调，也无法切换布局做对比 |

另一个隐患：超边轮廓颜色按超边在数组中的**下标**取色（`spec.ts` 中 `hyperedgeColors[i % n]`），一旦隐藏某条超边，后面所有超边都会换色。改版需要先把颜色改成按超边 id 固定。

## 2. 借鉴 hnxwidget 什么、改什么

| hnxwidget | 本设计 |
| --- | --- |
| 节点表 / 超边表：勾选、度数条、标签、类型、可见性、颜色 | **照搬**为「实体」「超边」两个 Tab |
| 度分布直方图，点柱子选中节点 | **照搬**，放在「统计」Tab，另加超边大小分布 |
| 勾选与画布选择双向联动，Shift 多选 | **照搬**；hypergraph-viz 需要支持集合选择（§6） |
| 隐藏后节点变淡，**轮廓不重排** | **改进**：隐藏 = 从布局输入中去掉，重新布局；画布顶部显示「已隐藏」标签条，对应 4.3c「隐含枢纽移到图例」 |
| 配色面板：按字段着色、调色板、字号、节点大小 | **保留并扩充**为「渲染」Tab：布局、超边轮廓、节点、标签 |
| 「隐藏」「移除」两种操作 | 合并为「隐藏」 |
| 无枢纽提示、无连通分量 | **新增** |

## 3. 面板结构

宽度从 w-72（288px）加到 w-96（384px），右上角可折叠。（实现时改为不分 Tab：统计、实体、超边、渲染四张可收起的卡片纵向排列，见 §9。）

```
┌─ 右侧面板 w-96 ────────────────────────┐
│ [统计] [实体 40] [超边 32] [渲染]    ⇥ │
│ ┌────────────────────────────────────┐ │
│ │                                    │ │
│ │         （当前 Tab 内容，见 §4）    │ │
│ │                                    │ │
│ └────────────────────────────────────┘ │
│ ─ 已选 2 ─ [只看所选] [隐藏] [清除]    │  ← 有勾选时出现，各 Tab 共用
│ ═ 详情 ════════════════════════ [▾] ═ │  ← 固定占面板 38% 高度，可折叠
│ 超边 · CausalExplanation               │
│ description: …                         │
│ members (5): 英伟达 营业收入 …          │
└────────────────────────────────────────┘
```

「详情」保留现在 `DetailsPanel` 的行为（悬停 / 点击的超边与实体，`PropertyList` 渲染），只是挪到面板下部，不随 Tab 切换消失。

## 4. 四个 Tab

### 4.1 统计

```
实体 40   超边 31   连线 1   最大超边 8
平均度数 4.1   连通分量 1
（有隐藏时：实体 37 / 40 …）

实体类型构成  ▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇  （按类型颜色堆叠，点色段 = 选中该类型）
  ●财季 10 ●指标 7 ●机构 7 ●业务范围 6 ●主题 5 …

实体度数分布                超边大小分布
█                           ▃▅█▃▂▁
█ ▁ ▁▁   ▁    ▁  ▁ ▁        2 3 4 5 6 7 8
1 …            32           （点柱子 = 选中该区间并跳到对应 Tab）

⚠ 3 个枢纽实体：超大规模云(范围) 32/32、英伟达 26/32、营业收入 19/32
  [全部隐藏]  [只选中]
```

- 统计对象是当前子图；有隐藏时同时给出「显示 / 全部」。
- 示例数字为 NVDA 子图（40 实体，32 条超边中 3 元及以上 31 条、2 元 1 条，最大 8，平均度数 4.1，1 个连通分量）。GoT S1E2 为 2 个连通分量（28 + 10，即维斯特洛和厄索斯）。
- 枢纽：所在超边数 ≥ 子图超边总数的 50%，且子图超边数 ≥ 6。NVDA 命中 3 个；GoT 最高 7/26，不提示。
- 直方图、构成条用纯 SVG，不引图表库。

### 4.2 实体

```
类型 [●财季 10] [●指标 7] [●机构 7] … [全部]    🔍 筛选
┌──┬──────────┬───────────────────┬────┬────┐
│☐ │ 度数 ▾   │ 名称              │ 色 │ 👁 │
├──┼──────────┼───────────────────┼────┼────┤
│☐ │████ 32   │超大规模云(范围) 枢纽│ ■  │ 👁 │
│☑ │███  26   │英伟达  ◎中心       │ ■  │ –  │
│☐ │██   19   │营业收入       枢纽 │ ■  │ 👁 │
│☐ │▌     4   │资本开支            │ ■  │ 👁 │
│░ │▏     1   │（已隐藏，行变灰）   │ ■  │ ⊘ │
└──┴──────────┴───────────────────┴────┴────┘
```

- 列：勾选 · 度数（条 + 数字，= 该实体在本子图中所属超边数）· 名称（类型色点 + 名称，标记「中心」「枢纽」）· 颜色 · 显隐。
- 点表头排序（度数、名称、类型）；类型按钮多选筛选，同时是图例；表头勾选框 = 全选当前筛选结果。
- **颜色**：类型按钮上的色点点开取色器，改的是**该类型**的颜色；行内色块改的是**单个实体**的颜色（覆盖类型色，行内显示小圆点标记，可「恢复类型色」）。
- 中心实体不能隐藏（显隐按钮置灰），否则布局失去锚点。

### 4.3 超边

- 列：勾选 · 大小（条 + 数字）· 名称（`type` 徽标 + description 截断）· 颜色 · 显隐。
- 上方按 `type` 筛选（有 `type` 字段时），如 CausalExplanation / FinancialFact / Guidance。
- **颜色**：行内色块改单条超边的轮廓色；「渲染」Tab 中可切换为「按超边类型着色」，此时 `type` 按钮上的色点改的是该类型。
- 图模式下不绘制的 3 元及以上超边，行内注明「图模式不绘制」，仍可勾选和隐藏。

### 4.4 渲染

| 分组 | 设置 | 选项（默认值加粗） | 改动后 |
| --- | --- | --- | --- |
| 布局 | 布局算法 | **超图布局（HypergraphLayout）** / 力导（force）/ ForceAtlas2 / 环形 | 重新布局 |
| | 以中心实体为中心 | **开** / 关 | 重新布局 |
| | 节点间距 `nodeSpacing` | 10–100，**50**（仅超图布局） | 重新布局 |
| | 标签防重叠 | **开** / 关（仅超图布局） | 重新布局 |
| | 图模式下 3 元及以上超边 | **丢弃**（`binary`）/ 拆成两两连线（`clique`） | 重新布局 |
| 超边 | 显示轮廓 | **开** / 关（关闭后只看节点布局） | 重绘 |
| | 轮廓范围 | **只圈节点** / 包含标签 | 重绘 |
| | 着色 | **按超边** / 按超边类型 | 重绘 |
| | 填充透明度 | 0–0.6，**0.2** | 重绘 |
| 节点 | 着色 | **按实体类型** / 统一颜色 | 重绘 |
| | 大小 | **固定** / 按度数 | 重新布局（大小影响间距） |
| 标签 | 显示 | **全部** / 仅中心与枢纽 / 不显示 | 重绘（防重叠开启时重新布局） |
| | 字号 | 10–16，**12** | 同上 |
| | | [恢复默认] | |

- 把超图布局切到「力导」即得到改造前的第一版效果，可直接在界面上做 4.3b 的前后对比；「环形」接近 HyperNetX 的默认画法。
- 设置项标注「重新布局」或「重绘」，重绘类（颜色、透明度、轮廓开关）不触发布局，拖动取色器时节点不跳动。
- 渲染设置和颜色存在 `localStorage`（所有数据源共用；颜色按类型名 / 实体 id / 超边 id 记录），刷新后保留；选择、隐藏不保存，换中心实体或数据源时清空。

## 5. 交互语义

| 操作 | 来源 | 结果 | 重新布局 |
| --- | --- | --- | --- |
| 勾选实体 | 表格；画布点实体（Shift 追加） | 所选实体高亮；含任一所选实体的超边保持正常，其余变淡 | 否 |
| 勾选超边 | 表格；画布点轮廓 / 连线（Shift 追加） | 所选超边及成员高亮，其余变淡（现有单选推广到多条） | 否 |
| 点直方图柱子 / 类型色段 / 枢纽「只选中」 | 统计 Tab | 选中对应元素集合，跳到对应 Tab | 否 |
| 悬停表格行 | 表格 | 画布上该元素临时高亮（G6 `active` 状态） | 否 |
| 悬停 / 点击画布元素 | 画布 | 表格滚动到对应行并标亮；详情区照旧更新 | 否 |
| 隐藏 | 行内 👁、批量条、枢纽「全部隐藏」 | 去掉该实体：所在超边删去该成员，剩不足 2 个成员的超边一并去掉；隐藏超边则直接去掉 | 是 |
| 只看所选 | 批量条 | 隐藏所有未选元素 | 是 |
| 恢复 | 画布顶部「已隐藏」标签条 ×、全部恢复、行内 ⊘ | 放回 | 是 |
| 改颜色 / 透明度 / 轮廓开关 | 实体、超边、渲染 Tab | 只改样式 | 否 |
| 改布局参数 | 渲染 Tab | 按新参数布局 | 是 |
| 换中心实体 / 数据源 | 左侧栏 | 清空选择与隐藏，保留渲染设置和颜色 | 是 |

选择以 id 记录，重新布局后仍有效；被隐藏的元素自动移出选择。

## 9. 实现记录

与上文设计的偏差：

- 不分 Tab：统计、实体、超边、渲染为四张可收起的卡片，纵向排列在一个滚动区内。统计、实体、超边默认展开，首屏可同时看到；实体、超边两张表平分剩余高度（各至少 176px，表内滚动），收起一张时另一张占满；渲染默认收起。统计卡片压缩为一行数字、类型构成条（图例见实体表的类型按钮）、两张直方图和枢纽提示；点柱子或色段时展开对应的表；
- 详情区默认收起；
- 详情区展开时固定占面板 38% 高度，没有做拖动分隔线；
- 「枢纽」包含中心实体（标注“中心”）：邻域子图中中心实体出现在每条超边里；中心实体和其他实体一样可以隐藏（表格眼睛按钮、隐藏所选、枢纽“全部隐藏”），隐藏后不再以它为布局中心，可以看去掉中心后其余实体的结构；
- 有选择时，悬停画布不再改变详情区（详情区显示点选的元素）；点表格行名称在详情区显示该行。

- 左侧栏（原设计不改）后来按同样的样式重做：数据源（默认展开，标题行显示当前数据源；加载出错时显示错误）、数据库信息（与右侧统计卡片相同，按已载入的子图并集统计；默认数据只带了部分实体的子图，另注明数据库总数；点类型色段筛选实体列表）、实体列表（类型筛选、按子图实体数或名称排序，分页保留）、超边列表（各子图超边的并集，类型筛选，按大小排序；点一条时，若当前子图含有它就直接选中，否则以其成员中子图最大的实体为中心加载后选中）；
- 所有卡片的展开 / 收起箭头在标题行右侧；
- 实体类型颜色按整个数据源分配（原来按左侧列表当前页分配，翻页、筛选后颜色会变），左右两栏一致

开发中发现并修复的问题：

| 问题 | 位置 | 修复 |
| --- | --- | --- |
| 隐藏实体后重新渲染报 `Unknown element type of id`：G6 bubble-sets 在成员变化后，按旧成员缓存移除区域时对已删除节点调用 `getElementType` | `hover-bubble-sets.ts` | 成员变化时清空缓存（`init()`）再算路径 |
| 超边的 `type` 字段（如 HIF 的 `CausalExplanation`）被带到 2 元连线上，G6 当成连线类型，报 `element ... is not registered` | `spec.ts` | 连线不带 `type`、`style`、`states`；悬停时从产生它的超边补回属性 |
| 只改颜色、状态时，每个元素更新都触发一次轮廓重算 | `hover-bubble-sets.ts`、`view.ts` | 样式 / 状态更新期间跳过轮廓重算（`SUPPRESS_CONTOUR_UPDATE`） |
| React 组件的 ref 在视图创建前就固定为 null | `react.tsx` | ref 改为转发到当前视图的对象 |
| HIF 解析只读节点的 `properties`，不读标准的 `attrs`（实体类型全部丢失）；超边属性取自关联记录而非超边本身 | `src/hifParser.js` | 读 `attrs`；超边属性取 `edges[].attrs` |
| 切换数据源后先选中第一个实体、随后又被清空，画布空白 | `HypergraphViewer.jsx` | 先清空再加载列表 |
| 悬停卡片显示布局用的 `cluster` 字段 | `constants.js` | 加入 `EXCLUDED_KEYS` |
